# Too ADHD to read

A single-file reader for people who find dense pages hard to stay with. Paste English or French text, read it on a calmer page, and click a word for a short gloss.

Open [the live site](https://yahexu.github.io/too-adhd-to-read/) on a computer or phone. No account.

## How to use

1. Paste a passage and click **Start reading**.
2. Click a word for a gloss. Set **Gloss** to ZH, EN, or FR.
3. Optional attention modes: **Spotlight** (current sentence bright) or **RSVP** (one word at a time).
4. **A−** / **A+** change type size. **Speak** reads the source word.

## Privacy

Reading layout stays in your browser. A lookup sends **only the clicked word** (or the current sentence if you ask) to a public translation API. The full document is never uploaded. Font size and language choices stay in `localStorage` on your device.

## Local copy

Download `index.html` and open it in a browser. Gloss lookups need the network; reading modes work offline.
